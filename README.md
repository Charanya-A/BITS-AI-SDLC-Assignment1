# BITS AI-SDLC – Assignment 1

This repository contains my implementation of Assignment 1 for Specification-Driven Development and AI-Assisted Engineering.

The assignment is organized into two parts.

## Part 1A – Smart Todo Manager

A task-management application that allows users to:
- Create tasks.
- Edit task details.
- View existing tasks.
- Update task status.

**Technology:** React, Vite, Node.js, Express.js and local JSON-based storage.

## Part 1B – Customer Message Spam Classifier

A customer-message classification application that accepts an English message and produces one of three results:
- SPAM
- HAM
- REVIEW

The application uses TF-IDF feature extraction and a Multinomial Naive Bayes classifier. It also displays a confidence value and applies a review threshold.

**Technology:** Python, Streamlit and Scikit-learn.

## Repository Structure

- `Part-1A/` – Smart Todo Manager source code, specifications, tests and supporting engineering artifacts.
- `Part-1B/` – Customer Message Spam Classifier source code, specifications, tests and supporting engineering artifacts.

## Development Approach

The projects were developed using a specification-driven workflow. The repository includes relevant specifications, plans, task breakdowns, implementation files, tests and harness-related evidence.
